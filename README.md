## Mô tả bài làm
Bài thực hành xây dựng website bán hàng đơn giản bằng NextJS App Router và Tailwind CSS.

## Chức năng đã hoàn thành
- Hiển thị danh sách sản phẩm từ FakeStoreAPI
- Responsive grid cho mobile/tablet/desktop
- Navbar giao diện chung
- Component tái sử dụng: Button, ProductCard
- Trang chi tiết sản phẩm với dynamic route `/product/[id]`

## Cách chạy project
```bash
npm install
npm run dev
